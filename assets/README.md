# Assets

- `svg/` is filled by `npm run assets` (characters, pictures, patterns, decor, logos from Figma). `qr-designformation.svg` is already here.
- `audio/` is filled by `npm run audio` (voice lines and sound effects from ElevenLabs) together with `audio/manifest.json`.

Commit these files; they are what the game loads. Never commit `.env`.
